إضافة صفحة مركز العمليات (Operations Center)

صفحة داشبورد جديدة كاملة بواجهة واحدة تحت "لوحة التحكم" وفوق "المناطق/الشحنات" في القائمة الجانبية، تشمل:
- شريط كروت إحصائيات علوي (إجمالي، تم التسليم، قيد التوصيل، مرتجعة، تقييم، إيرادات)
- مركز العمليات: شحنات متأخرة، شحنات فيها مشكلة، شحنات خارجة اليوم، المندوبين المتاحين، عملاء يحتاجون متابعة
- خريطة مباشرة (نسخة تجريبية بصرية)
- مؤشرات الأداء الرئيسية (KPIs) بعدادات دائرية
- ملخص الأرباح واتجاه الإيرادات والأرباح
- مركز الذكاء الاصطناعي (تنبيهات ذكية)
- أفضل العملاء (مع Health Score) وأفضل المندوبين
- توزيع الشحنات حسب الحالة، أحدث التنبيهات، آخر الشحنات
- إجراءات سريعة وجدول المندوبين اليومي
- شاشة ملخص المدير التنفيذي

المرحلة الحالية: تصميم UI بالكامل باستخدام بيانات تجريبية (mock data) في ملف منفصل
lib/operations-center-mock-data.ts، تمهيداً لربط الـ API لاحقاً.

الصفحة الحالية "لوحة التحكم" لم يتم المساس بها إطلاقاً.
